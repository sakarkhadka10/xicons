# Security Policy

## Supported versions

Only the latest published minor version of each `@axcore/xicons*` package receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via
[GitHub private vulnerability reporting](https://github.com/sakarkhadka10/xicons/security/advisories/new).

Include steps to reproduce and the affected package/version. You can expect an initial response within 7 days.
Relevant areas include SVG injection (icon markup, `toSvg` attributes, the CDN `/icons` endpoint) and supply-chain issues.
